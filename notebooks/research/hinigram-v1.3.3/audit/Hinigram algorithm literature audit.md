# Hinigram V1.2 Works Only in Simulation

Hinigram V1.2 is not yet mathematically or methodologically sound as a respiratory-rate monitor or waiting-room triage aid. Its equations are mostly correct on their own terms, but its assumptions about the ESP32 hardware are wrong, several stages remove or invent the signal they claim to measure, and every headline result was scored against a simulator built on the same assumptions as the estimator. The team's three-node CSV has no breathing ground truth, yet it already falsifies five input assumptions: the real-time runtime assumes 100 Hz and pools all three links into one buffer (the nodes deliver about 28.7 Hz each); the replay path resamples on a host clock with about 133 ms of jitter; the subcarrier selection feeds 11 null bins into the ratio; the simulator assumes stable amplitude, though real packets jump between gain levels in 3 to 9 dB steps; and breathing is assumed always measurable, though motion fills 17% of the session. Further down the chain, the cross-subcarrier ratio cancels most of the breathing signal along with the gain noise. The adaptive Stuart-Landau oscillator is exactly a type-2 phase-locked loop whose noise bandwidth is wider than the breathing band, so it reports about 22 breaths/min from pure noise. The PLV "coherence" compares the oscillator with its own input and scores 0.78 to 0.84 on noise. The "ResoNet" classifier is a fixed random reservoir, not the trained network in the team's EEG paper, and its sync-versus-power ablation repeats the capacity confound that paper warns against. The Fresnel localizer, the "50-patient" Bland-Altman (r = 0.998) and the MIMIC-III calibration all grade the simulator against itself. Clinically, the rules are looser than NEWS2, qSOFA and ESI, cannot represent infant breathing above 36/min, and fire RED on 6-second pauses that no clinical apnea definition recognizes. In Philippine emergency rooms running at 138 to 400% of capacity that means ignored alarms, and the "Immediate Resuscitation" wording would likely make the system an ASEAN Class C medical device. The salvageable core is real: 28.7 Hz per node is plenty, Espressif's gain compensation (or, failing that, per-packet normalization) removes the gain steps, the team's ResoNet paper already models the surrogate controls and paired statistics a credible V2 needs, and a calm, bilingual, four-state dashboard can pass the contrast and color-blind checks the current one fails.

## The three-node CSV breaks five input assumptions before any math runs

The CSV is a format sample with no breathing reference, so it cannot say whether V1.2 measures breathing accurately. It can say whether V1.2 reads the hardware correctly, and five of its assumptions fail that test. V1.2's filter, oscillator and runtime functions all default to **fs = 100 Hz** (Section 2 code cell; Section 3 code cell; Section 7 code cell). The CSV shows **three MACs on channel 6 in strict round-robin at 28.45 to 28.87 Hz each**, about 86 Hz pooled. The real-time worker appends every decoded packet to a single ring buffer whatever its node_id (Section 7 code cell, lines 77-78). Its 136-byte wire frame carries a node number, sequence counter, channel and RSSI but no receiver timestamp (Section 1 code cell, lines 66-70). Fed packets in the measured round-robin pattern, the worker would treat three links, each with its own oscillator, static channel and gain, as one 100 Hz signal. A nominal 6-second window of 600 packets would actually span about 7.0 s. The time axis would be stretched so that any recovered rate comes out **about 16% high**, the 0.12-0.60 Hz passband would land at 0.10-0.52 Hz, and np.unwrap would see packet-to-packet jumps equal to the phase offsets between links ([audit arithmetic](audit_scripts/report_checks.py)). Splitting the buffer by node without resampling would be worse: a **3.5x scale error** that moves the passband to 2.1-10.3 breaths/min of true rate and pushes normal adult rates outside it. Testing could not expose this, because run_hil_simulation always reads from VirtualESP32SerialPort, which synthesizes a single link and simply stamps packets as nodes 1, 2 and 3 in turn (Section 7 code cell, lines 1-27 and 55).

The CSV-replay path in cell_17 has the right structure: it splits by MAC and resamples each link onto a uniform 30 Hz grid. But it interpolates on t_pc, the PC host time, instead of ts_us, the receiver's local timestamp (Section 8 setup cell, lines 226-231 and 350-353). Espressif defines that field as the local receive time in microseconds, "precise only if modem sleep or light sleep is not enabled" ([esp_wifi_types_native.h](https://github.com/espressif/esp-idf/blob/383dda6c182e3dabf6355160166fe007df775629/components/esp_wifi/include/local/esp_wifi_types_native.h)). The CSV confirms it is far steadier than the host clock, whose offset from it has a standard deviation of **about 133 ms, or 3.8 packet intervals**. The oscillator computes its rate over a 3.5 s span, and endpoint timing errors of that size are worth about 5% of rate there (0.8 breaths/min at 15/min), falling to 0.6% over a 30 s window (audit arithmetic, audit_scripts/report_checks.py). The receiver counter is 32-bit and wraps every 71.6 minutes, so it must be unwrapped per MAC before resampling.

Subcarrier handling fails more quietly. For this non-HT 20 MHz configuration, Espressif stores one LLTF of 64 bins in FFT order (0 to 31, then -32 to -1), imaginary part first, with 52 usable bins. When first_word_invalid is set, the first four bytes are invalid ([ESP-IDF CSI documentation](https://github.com/espressif/esp-idf/blob/383dda6c182e3dabf6355160166fe007df775629/docs/en/api-guides/wifi-driver/wifi-vendor-features.rst); [esp-radar subcarrier table](https://github.com/espressif/esp-csi/blob/423c26d493074f4ac659394f2e363ab8267cf73b/components/esp-radar/src/csi_sub_carrier_table.c)). The CSV matches exactly, with **51 valid bins at slots 2-26 and 38-63**. V1.2's parser gets the bytes right, dropping the first four and reading imaginary-first (Section 8 setup cell, lines 88-96). The analysis then keeps the first 56 of the remaining 62 bins, which **pulls in the 11 null or near-null slots 27-37 and throws away six valid bins** (subcarriers -6 to -1). The 64-bin path is worse. Its ACTIVE_56 mask was written for fftshifted data with DC in the middle, so on ESP32 ordering it keeps 10 guard nulls and scrambles frequency order (Section 1 code cell, line 71). Ratios built on those bins are either exactly zero or random-phase noise, and both flow into unwrapping and FastICA. The same mismatch quietly moves the ratio's reference. ref_idx = 0 is commented as a high-amplitude reference "near band edge" (Section 2 code cell, lines 1-15). That holds in the fftshifted simulator, where it is subcarrier -28. On real data it means subcarrier +2 or +4, right beside DC. Because min_spacing counts array positions rather than frequency, it also lets through subcarriers only a few bins from the reference on the other side of the DC gap.

The CSV's most consequential feature is gain switching. Amplitude toggles between discrete AGC levels in **steps of 3 to 9 dB, with a 35 to 47% chance of switching on any packet**. That is about 10 to 14 switches per second per node, more often on weaker links. Espressif treats exactly this as a per-packet scalar impairment. Its esp-radar code reads hidden fft_gain and agc_gain bytes, takes a median baseline over 50 packets, and rescales CSI by 10^(-((agc - agc_base) + (fft - fft_base)/4)/20), or else forces a fixed gain. It compiles that path only for the ESP32-S3, C3, C5, C6 and C61 ([wifi_rx_gain_t.c](https://github.com/espressif/esp-csi/blob/423c26d493074f4ac659394f2e363ab8267cf73b/components/esp-radar/src/wifi_rx_gain_t.c); [esp_radar_t.h](https://github.com/espressif/esp-csi/blob/423c26d493074f4ac659394f2e363ab8267cf73b/components/esp-radar/include/esp_radar_t.h); [csi_recv example](https://github.com/espressif/esp-csi/blob/8633d67152db2808f141cc1595970aa9cf406045/examples/get-started/csi_recv/main/app_main.c)). Visible toggles mean either the receiver is an original ESP32 or its firmware skips compensation. That is worth checking, because V1.2 labels its nodes ESP32-S3. If the switching is modeled as a symmetric two-level random switch, **3.8 to 6.2% of its variance falls inside 0.12-0.60 Hz, leaving in-band amplitude noise of roughly 3 to 12% of the mean** that no bandpass filter can remove (audit arithmetic, audit_scripts/report_checks.py). This corrupts any raw-amplitude method, including the groupmate's csi_live.py spectrum of mean |H| that cell_17 reproduces (Section 8 setup cell, lines 216-221). V1.2's cross-subcarrier ratio does cancel a common per-packet scalar, which is a genuine strength of the design, but the next section shows what that cancellation costs.

Motion episodes near 0-17 s, 63-68 s and 100-107 s cover only 29 s (16.8%) of the 173 s session. But every sliding window that touches an episode is contaminated, so they spoil **24.6% of 6 s windows, 45% of 20 s windows and 62% of 30 s windows** (audit arithmetic, audit_scripts/report_checks.py). The long windows that rate accuracy needs therefore require motion-aware estimation: detect movement, exclude or down-weight those samples, and show "no reliable reading" instead of a number. Packet rate, by contrast, is comfortably adequate. NIST found classifier accuracy "does not drop significantly" as the WiFi frame rate fell from 10 to 3 per second, and Hillyard's 20-patient sleep-lab study reached a 0.60 breaths/min median error with CSI at 9.9 Hz ([NIST BreathSmart](https://tsapps.nist.gov/publication/get_pdf.cfm?pub_id=935107); [Hillyard et al.](https://arxiv.org/pdf/1807.06767)). The roughly 28.7 Hz per node probably reflects the serial link. Espressif's csi_recv console runs at 921,600 baud ([csi_recv sdkconfig](https://github.com/espressif/esp-csi/blob/8633d67152db2808f141cc1595970aa9cf406045/examples/get-started/csi_recv/sdkconfig.defaults)), which caps 600-700 character ASCII lines at about 130 to 150 per second, against about 680 per second for V1.2's own 136-byte binary frame (audit arithmetic, audit_scripts/report_checks.py). Finally, the cell_17 demo-CSV generator contains none of these impairments. Its host and receiver clocks are identical, it has no gain steps and no motion, and it programs a ±3.8-count breathing modulation onto an amplitude of about 18 counts (Section 8 setup cell, lines 123-197). That gap between simulator and hardware, more than any single formula, is why V1.2 looks accurate.

| V1.2 assumption | What the CSV shows | Consequence | Fix |
|---|---|---|---|
| One stream at fs = 100 Hz | Three MACs in round-robin, 28.45 to 28.87 Hz each | Pooled: three links blended, rates about 16% high. Split at 100 Hz: 3.5x error | Buffer per MAC, use the measured rate, decimate to 5-10 Hz |
| Host time is accurate enough | Host-vs-receiver offset SD about 133 ms | About 5% rate error over a 3.5 s span | Resample on unwrapped receiver µs timestamps |
| 56 active subcarriers start at index 0 | 51 valid bins: slots 2-26 and 38-63 | 11 null bins used, 6 valid bins dropped, reference beside DC | Keep the 51 valid bins in true frequency order |
| Amplitude is stable packet to packet | AGC steps of 3 to 9 dB on 35 to 47% of packets | 3 to 12% in-band amplitude noise without normalization | Gain compensation or forced gain on S3/C3/C6; per-packet normalization otherwise |
| Breathing is always present and clean | Motion at 0-17, 63-68 and 100-107 s | 25% of 6 s and 62% of 30 s windows contaminated | Motion detector plus a grey "no reliable reading" state |
| A high packet rate is needed | 28.7 Hz per node, 1.8 to 3.3% loss | Already adequate (3 to 10 Hz suffices) | Keep the rate; interpolate short gaps |

## The ratio and ICA chain cancels the breathing it was built to isolate

V1.2 borrows its central idea from FarSense, but the physics does not carry over. FarSense divides the CSI of two antennas on one card. That works because "the time-varying phase offset is the same across different antennas on a Wi-Fi card as they share the same RF oscillator", while the two antennas still see different geometry. The result reached a **0.28 breaths/min mean absolute error (MAE) at 6 m** and worked out to 8 m ([FarSense](https://arxiv.org/pdf/1907.03994)). A ratio of two subcarriers on one antenna cancels only what all subcarriers share: the AGC scalar and the carrier-frequency offset. It keeps the timing-offset term, which SpotFi shows is linear in subcarrier index ([SpotFi](https://courses.grainger.illinois.edu/CS598WSI/sp2021/Papers%5CSpotFi_SIGCOMM15.pdf)). It also cancels most of the breathing, because within a 20 MHz channel the chest path's phase rotation differs by at most ±0.36% across subcarriers. With one dominant static path, the breathing term that survives in the ratio scales as 2|sin(πΔfΔτ)|, where Δf is the frequency gap to the reference and Δτ is the chest path's excess delay. Take the project's nearest chair-to-link geometry (12.7 cm excess path) with a reference beside DC: **at most about 2.5% of the breathing modulation survives, roughly a 40-fold attenuation**. At 1 m of excess path the figure is 18%, against 34% if the reference sat at a band edge as the code comment intends (audit arithmetic, extending the earlier derivation). The team's synthetic generator hides this by imposing ±30% subcarrier-to-subcarrier variation in breathing depth, roughly 80 times what the physics allows (Section 1 code cell, lines 196-214).

The only cross-subcarrier-ratio respiration work the research found, SA-WiSense, is an unreviewed preprint, and it works around these limits rather than ignoring them. It uses an ESP32 at 40 MHz with 218 subcarriers sampled at 120 Hz. A genetic algorithm picks the numerator, denominator and weights to maximize breathing-band SNR. It reports "over 91.2%" of estimates within 1 breath/min up to 8 m for five seated subjects, but gives no MAE ([SA-WiSense](https://arxiv.org/pdf/2507.17623)). V1.2 cites that search but hard-codes reference index 0 and a fixed spacing (Section 2 code cell). The better-supported pattern is to select subcarriers by breathing-band SNR rather than fix them in advance. FarSense combines only subcarriers whose breathing-to-noise ratio exceeds 0.7 of the maximum. RespirFi, a single-antenna method, uses amplitude alone because single-antenna phase is unreliable. A 2026 subcarrier-aware preprint loses 15% accuracy when it falls back to one arbitrary subcarrier ([FarSense](https://arxiv.org/pdf/1907.03994); [RespirFi](https://arxiv.org/pdf/2604.20397); [subcarrier-aware method](https://arxiv.org/pdf/2608.25612)). For the ESP32 the best route depends on the chip. On an S3, C3 or C6 receiver, Espressif's gain compensation, or a forced fixed gain at some cost in packet loss, removes the AGC steps while keeping the common-mode breathing modulation that any ratio or normalization throws away ([esp_csi_gain_ctrl](https://components.espressif.com/components/espressif/esp_csi_gain_ctrl)). On an original ESP32, the fallback is to divide each packet by its mean magnitude over the 51 valid bins. That cancels the gain and loses the same common-mode breathing as the ratio, but it uses a robust band-wide average as the reference instead of one subcarrier beside DC. Either way, the next step is to rank subcarriers or I/Q projections by breathing-band SNR, exploiting whatever frequency-selective multipath the room provides. A true FarSense ratio needs phase-coherent receivers, which Espressif now offers as esp-crab: two ESP32-C5 chips sharing one crystal oscillator ([esp-crab](https://github.com/espressif/esp-csi/blob/8633d67152db2808f141cc1595970aa9cf406045/examples/esp-crab/README.md)).

The phase path then unwraps a signal that has not been sanitized. SpotFi removes the per-packet timing slope by fitting and subtracting a line across subcarriers ([SpotFi](https://courses.grainger.illinois.edu/CS598WSI/sp2021/Papers%5CSpotFi_SIGCOMM15.pdf)). V1.2 skips that step, so each ratio's phase carries the slope multiplied by its index distance from the reference. If ESP32 packet-detection jitter is near one 50 ns sample, a figure no source has measured, that adds **0.8 to 4.9 rad of random phase per packet** for index gaps of 8 to 50. The breathing signal itself is tens of milliradians to 0.5 rad, and np.unwrap's assumption of steps smaller than π breaks down. The Hampel stage cannot repair this. A 2π unwrap slip is a level shift, not an outlier, so it passes through unchanged. Meanwhile the centered 15-sample, 3σ window flags **2.00% of pure Gaussian samples against a nominal 0.27%** ([more_checks.py](audit_scripts/more_checks.py)). The demo "scrubbed" 4,752 samples, 4.1% of the data, when only about 0.5% had been corrupted (Section 2 code cell output). With int8 CSI the median absolute deviation can also collapse to zero, at which point the code's 1e-8 floor flags every sample that deviates at all (Section 2 code cell, lines 18-44; [Pearson et al. 2016](https://doi.org/10.1186/s13634-016-0383-6)).

FastICA compounds the problem. On each 6 s window it whitens about 46 ratio streams down to two components (Section 2 code cell, lines 47-139). Yet narrowband breathing over 6 s offers only about six effective degrees of freedom per channel, and ICA cannot determine the sign, order or scale of its sources ([ICA lecture notes after Hyvärinen and Oja](https://www.ibug.doc.ic.ac.uk/media/uploads/documents/independent_component_analysis.pdf)). The code picks the component per window by in-band energy and sets its sign by correlation with the channel mean, with no continuity across the 2 s hops, so identity and polarity can flip between updates. The runtime log already prints "FastICA did not converge". That is a warning, not an exception, so the code's try/except fallback never catches it (Section 7 code cell output). Marginal-distribution ICA on too few samples also overlearns, producing spurious bump-like components ([Särelä and Vigário 2003](https://jmlr.org/papers/v4/sarela03a.html)). Separating four seated people is out of reach. MultiSense needed **three antennas at each end** to separate four people at 0.73 breaths/min ([MultiSense](https://researchportal.ip-paris.fr/en/publications/multisense-enabling-multi-person-respiration-sensing-with-commodi/)). Yang et al. avoided separation altogether, placing one receiver per person using Fresnel geometry ([Yang et al. 2018](https://web.comp.polyu.edu.hk/labimcl/paper/Yang-2018-MASS-MultipersonRM.pdf)). A 6 s window resolves only 10 breaths/min, far too coarse to split V1.2's own test patients at 15 and 17.8/min. The four-patient demo never faced the problem, because it synthesizes each patient's CSI as a separate single-person stream (Section 5 code cell, line 162). The stable alternatives are PCA or second-order blind identification with a long-memory covariance ([Belouchrani et al. 1997](https://doi.org/10.1109/78.554307)), or simple quality-weighted fusion of per-subcarrier estimates.

The Butterworth bandpass is a reasonable band choice for adults, applied in a way that defeats it. butter(4, [0.12, 0.60]) is an eighth-order bandpass. Its group delay is **1.87 s at 0.25 Hz, 4.83 s at 0.15 Hz and 7.35 s at the 0.12 Hz edge**, where the gain has already fallen to 0.707. The RED bradypnea rule at 8 breaths/min therefore operates inside the filter's transition band ([dsp_checks.py](audit_scripts/dsp_checks.py)). The impulse response needs 8.2 s to deliver 99% of its energy. The live worker runs zero-phase sosfiltfilt with a 24-sample pad on each 6 s window (Section 7 code cell, line 87; [SciPy sosfiltfilt](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.sosfiltfilt.html)). That, like any per-window restart, leaves outputs heavily distorted by edge transients, with **50% normalized RMS error even on a pure in-band tone** ([dsp_checks.py](audit_scripts/dsp_checks.py)). The "strictly causal 31-tap FIR Hilbert" is defined but never called. Every phase actually comes from the FFT-based, non-causal scipy.signal.hilbert ([SciPy hilbert](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.hilbert.html)). The FIR would have failed anyway: its gain is only 0.033 to 0.195 across 0.1-0.6 Hz, and 1% accuracy down to 0.12 Hz needs 971 to 1,321 taps and 5 to 7 s of delay (Section 3 code cell, lines 1-14; [dsp_checks.py](audit_scripts/dsp_checks.py)). The "sub-5 ms latency" figure times per-packet arithmetic on stored data (Section 7 code cell, lines 126-149). Once you add the 6 s window, the 2 s hop, group delay, filter ring-down and the 6 s apnea counter, realistic apnea-onset detection latency is **on the order of 10 to 20 s**. Latency should be reported as a distribution that includes the maximum, with algorithmic delay kept separate from compute time ([Google SRE](https://sre.google/sre-book/service-level-objectives/); [Tene, via Treat](https://bravenewgeek.com/everything-you-know-about-latency-is-wrong/)). The fix is conventional: run one causal SOS filter continuously with its state carried across packets, decimate early to 5-10 Hz since breathing lies below 1 Hz, and keep centered smoothers and whole-window normalization out of the live path.

## The Hopf oscillator is a fast phase-locked loop that also locks onto noise

The oscillator stage is the project's most distinctive idea. Its math is internally consistent, but it is not what the code says it is, and it adds no accuracy. Righetti, Buchli and Ijspeert's adaptive Hopf oscillator forces only the x equation with the real input and learns frequency through dω/dt = -εF·y/r, using one gain ε for both ([Righetti et al. 2006](https://infoscience.epfl.ch/record/98363/files/righetti06b.pdf?version=1)). V1.2 instead drives both equations with the analytic signal and uses separate gains (Section 3 code cell, lines 56-67). Writing the state in polar form shows the result is **exactly a second-order, type-2 phase-locked loop (PLL)**: dθ/dt = ω + (K|F|/r)·sin(θ_F - θ) and dω/dt = ε|F|·sin(θ_F - θ), with proportional gain K|F|/r and integral gain ε|F| ([PLL loop equations, Georgia Tech ECE 6440](https://pallen.ece.gatech.edu/Academic/ECE_6440/Summer_2003/L090-PLLEqs&MeasA%282UP%29.pdf)). At the project's gains, the loop's noise bandwidth is **0.6 to 0.94 Hz, wider than the 0.2 to 0.33 Hz breathing it tracks** and at or above the 0.6 Hz band edge. So the oscillator follows whatever phase the filtered input has, noise included ([dsp_checks.py](audit_scripts/dsp_checks.py)). Righetti's own analysis predicts this trade-off: learning speed scales as ε², and "the faster the learning is, the higher the error of adaptation will be".

Simulation with the project's own functions confirms it. Rate error is in breaths/min, on 6 s windows, for true rates of 10 to 30/min, with 100 trials per noise level ([plv_sim.py](audit_scripts/plv_sim.py)):

| Input SNR | Hopf oscillator RMSE | Hilbert phase-slope RMSE | Zero-padded FFT peak RMSE |
|---|---|---|---|
| 20 dB | 1.03 | 0.52 | 0.71 |
| 10 dB | 1.51 | 1.10 | 1.51 |
| 3 dB | 4.88 | 3.37 | 4.13 |
| 0 dB | 7.21 | 7.36 | 6.95 |

Only at 0 dB does the oscillator edge out a plain Hilbert phase slope over the same span (7.21 against 7.36), and at 20 dB it is twice as bad. A second run at 3 dB gave 3.24 instead of 4.88, so the low-SNR differences sit within Monte Carlo noise ([seed_check.py](audit_scripts/seed_check.py)). More importantly, **pure band-limited noise with no breathing produces a confident "rate" of 22.6 ± 8.5 breaths/min** in 6 s windows, and 21.5 ± 3.9 in 40 s windows. Those values sit close to the band's spectral centroid (22.6) and its Rice zero-crossing rate (24.6) ([plv_sim.py](audit_scripts/plv_sim.py); [Rice 1944](https://doi.org/10.1002/j.1538-7305.1944.tb00874.x)). Several other features follow from the PLL view. The fast loop forgets its initial condition within the first 2 to 2.2 s, which the code discards anyway, so the look-ahead zero-crossing "cold start" seed is both acausal and irrelevant: seeded and unseeded runs had RMSEs within 0.06 breaths/min of each other. Both loop gains scale with |F|, so the dynamics depend on the per-window unit-variance normalization, which is a non-causal block AGC. The 0.65 Hz frequency clamp does not exclude the second harmonic of slow breathing (2 × 12 = 24/min), which matches the "[Harmonic Jump!]" annotations in cell_19. And the rate itself comes from the phase advance over a 3.5 s span, less than one breath at 15/min (Section 3 code cell, lines 117-127).

The PLV coherence metric is circular. It measures the mean phase agreement, over a centered 2 s window, between the Hilbert phase of the input and the phase of an oscillator driven by that same input (Section 3 code cell, lines 99-115). For any narrowband input it therefore measures how well the loop tracks, which is high by design. On pure band-limited noise it averages **0.84 on 40 s windows and 0.78 on 6 s windows**. Two completely independent noises still give a mean of 0.69 at 2 s, with 26% of windows above 0.9, and even 32 s windows leave a null mean of 0.19 ([plv_sim.py](audit_scripts/plv_sim.py)). In a simulated apnea, more residual noise produced a higher PLV, up to 0.98. The runtime log shows the consequences. During simulated apnea, PLV stayed at 0.997 and 0.982, and the RED came from the rate rule, not from coherence. A normal 15/min window scored 0.539 and became a YELLOW false alarm. A 29/min tachypnea was estimated at 18.24/min with PLV 0.928 and labeled GREEN (Section 7 code cell output). The "MIMIC-III calibration" loss, |f_est - f_gt| + 2(1 - PLV), explicitly rewards self-locking. It also ran on the synthetic fallback sine: the printed record id "mimic3_verified_resp" is the default set before any WFDB record loads (Section 1 code cell, lines 236-266; Section 3 code cell output). Worse, a PLV below 0.15 increments the apnea counter (Section 7 code cell, lines 91-94), so signal failures pile up as "apnea". PLV estimates are also biased upward at finite sample sizes, which is why the unbiased pairwise phase consistency was introduced ([Vinck et al. 2010](https://doi.org/10.1016/j.neuroimage.2010.01.073)).

The literature offers estimators with known statistics that make better use of the same idea. The state-space phase estimator models a rhythm as a damped, noise-driven rotating oscillator and tracks it with a Kalman filter, giving phase with 95% credible intervals. Discarding samples with wide credible intervals cut EEG mu-rhythm phase error from 40.5° to 11.2°, while keeping 16.4% of samples ([Wodeyar et al. 2021](https://www.biorxiv.org/content/10.1101/2021.03.25.437024.full.pdf)). It is the statistically principled version of what the Hopf oscillator attempts, and its uncertainty is a defensible quality index where the self-PLV is not. For rate itself, Charlton's benchmark of 314 algorithms found that time-domain breath detection with fusion and quality gating performed best ([Charlton et al. 2016](https://doi.org/10.1088/0967-3334/37/4/610)). "Smart Fusion" reports a rate only when estimates agree within 4 breaths/min ([Charlton, Villarroel and Salguiero](https://fileserver-az.core.ac.uk/download/586939810.pdf)). A respiratory quality index built from breath-to-breath regularity cut MAE by up to 36.89% ([Baker et al. 2021](https://researchonline.jcu.edu.au/67705/1/journal.pone.0249843.pdf)). Thomson's multitaper F-test gives a formal test for a breathing line in colored noise ([Thomson 1982](https://doi.org/10.1109/PROC.1982.12433)). Expectations should be calibrated too. The closest biosignal precedent, an adaptive-oscillator tracker for ECG-derived respiration, reached 4.53 to 4.77 breaths/min MAE against 4.94 to 5.49 for Fourier estimation, a real but modest gain ([Mirmohamadsadeghi and Vesin 2014](https://infoscience.epfl.ch/record/201743/files/CINC14_LM.pdf?version=1)). A sound V2 would estimate rate on 20 to 32 s windows updated every 1 to 2 s and withhold output when quality is low. If the oscillator stays at all, it should be a narrowband tracker with a stated noise bandwidth, accepting that a loop narrow enough to average noise takes tens of seconds to lock.

## ResoNet, Fresnel localization and the validation all grade the simulator against itself

### One name now covers three different models

The team's EEG paper evaluates a **trainable** bank of Stuart-Landau oscillators, whose encoder, damping and frequencies were all learned, on 14 subjects of the High-Gamma Dataset, with a capacity-matched surrogate control (team ResoNet paper (ResoNet.pdf)). Its honest findings were that the learned oscillators are "low-frequency damped resonators" with μ < 0, so "none self-oscillate"; that the linear uncoupled bank slightly outperformed the nonlinear one (-0.017); and that phase synchronization is "band-power-equivalent as a decoder". In Hinigram the name "ResoNet" covers two other objects. The classifier bank uses a random complex encoder fixed at seed 42, μ = -0.25 for all 12 oscillators, frequencies fixed at linspace(0.15, 2.5) Hz, and random coupling scaled by 0.08. Only a ridge readout is trained (Section 4 code cell, lines 14-28 and 104-112). That is reservoir computing: a fixed random dynamical system with a trained linear readout ([Lukoševičius and Jaeger 2009](https://doi.org/10.1016/j.cosrev.2009.03.005)). The rate tracker is a single self-oscillating (μ = 1) adaptive oscillator, which is the opposite regime. The paper's evidence covers neither, and the probe table titled "HopfProbe Learned Oscillator Bank Audit" describes nothing that was learned.

With μ = -0.25, the bank behaves as a set of complex one-pole resonators. This is the damped regime formalized by Izhikevich's resonate-and-fire model and by S4D-style state-space layers ([Izhikevich 2001](https://doi.org/10.1016/S0893-6080%2801%2900078-8); [Gu et al. 2022](https://arxiv.org/abs/2206.11893)). Each resonator has a 4 s time constant, 0.08 Hz bandwidth and a Q of about 3, and they are spaced 0.214 Hz apart. So **only three of the 12 oscillators sit inside the 0.12-0.6 Hz breathing band**, and 29% of each start-up transient is still present at the end of a 5 s window. Nonlinear and linear power features correlate at **0.92 to 0.99** per oscillator ([dsp_checks.py](audit_scripts/dsp_checks.py); [more_checks.py](audit_scripts/more_checks.py)). The probe's repeated 0.234 Hz "peak frequency" is simply the first non-DC Welch bin, 30 Hz divided by 128 samples; pure tones from 0.15 to 0.36 Hz all return it ([SciPy welch](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.welch.html)).

The sync-versus-power ablation then repeats the exact error the paper was written to expose. Comparing 132-144 synchronization features against 12 power features mixes up information content with readout capacity. In the paper those two effects were large and opposite: a +0.098 phase effect against a -0.101 capacity penalty, netting to a raw -0.003 (p = 0.90). The paper concluded that "raw readout ablations are inherently misleading" (team ResoNet paper (ResoNet.pdf)). Hinigram has no surrogate arm. Its four classes were programmed into the generator (Section 1 code cell, lines 107-161). Its arms were scored on a single split, with test sets of 80 and 300 that cannot be paired. At n = 80, four-class accuracy needs at least 27 correct (33.75%) to beat chance at p ≤ 0.05. An 85% accuracy carries a ±7.8-point 95% interval, and a 12-versus-5 split of discordant answers gives an exact McNemar p of only 0.14 ([stats_check.py](audit_scripts/stats_check.py); [Combrisson and Jerbi 2015](https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=DOI:10.1016/j.jneumeth.2015.01.010&resultType=core&format=json); [Dietterich 1998](https://mlanthology.org/neco/1998/dietterich1998neco-approximate/)). The remedy is already in the team's paper. Build a dimension-matched surrogate by independently circular-shifting each stream, and report three Holm-corrected paired contrasts (sync minus surrogate, surrogate minus power, sync minus power). Use repeated cross-validation with identical folds and a band-power baseline tuned just as carefully. Above all, use real CSI.

### Fresnel zones are 6 cm wide, so a 1.15 m Gaussian cannot localize anyone

Fresnel zones are confocal ellipsoids whose boundaries sit at excess path nλ/2, which at channel 6 means **a new zone every 6.15 cm** ([Wital](https://arxiv.org/pdf/2305.14490)). Amplitude sensing is best mid-zone and worst at zone boundaries ([Guo et al., preprint](https://arxiv.org/pdf/2009.09715)). Yang et al. measured **0.614 breaths/min MAE mid-zone against 3.130 at a boundary** ([Yang et al. 2018](https://web.comp.polyu.edu.hk/labimcl/paper/Yang-2018-MASS-MultipersonRM.pdf)). In V1.2's own room geometry, a seated person who shifts 3 to 5 cm crosses a full zone (11 cm for the chair nearest a link's line of sight). Against that structure, the localizer's exp(-(excess/1.15 m)²) spans about 19 zones and changes by **at most 4.6% of its peak across any one zone** (1.5% near the closest chair). It also falls to 0.003-0.010 at 2.2-2.5 m of excess path, which contradicts FarSense detecting breathing 8 m away (audit arithmetic; [FarSense](https://arxiv.org/pdf/1907.03994)). The validation is circular as well. The "measured" link weights are the model's own sensitivities plus N(0, 0.015) noise (Section 5 code cell, line 157). Estimates then snap to the nearest chair within 1.25 m. The reported "Raw Trilateration Err" is the distance between the estimate and the chair it snapped to, not the true position (Section 5 code cell, lines 126-139 and 180). As a result, **an estimate more than 1.25 m from every chair is reported as zero error**, and a snap to the wrong chair understates the miss. The furniture boxes are computed as true_size + 0.25 × (measured - true_size), which guarantees a 75% error reduction by construction. The "Rician K (dB)" column is a hard-coded formula, not a channel measurement. In the four-patient demo, apnea duration is set to a flat 10 s whenever PLV < 0.15 rather than measured (Section 5 code cell, lines 56-60 and 171). Using the same forward model to synthesize and invert data is the "inverse crime" that inverse-problems research treats as trivial ([Wirgin 2004](https://arxiv.org/abs/math-ph/0401050)). Real localization needs angle or time-of-flight resolution, which means several phase-coherent antennas and wide bandwidth. What the literature does support for three single-antenna 20 MHz links is Fresnel-guided deployment: one dedicated link per chair, positioned so the target sits mid-zone ([Yang et al. 2018](https://web.comp.polyu.edu.hk/labimcl/paper/Yang-2018-MASS-MultipersonRM.pdf)).

### The headline numbers would not survive a methods reviewer

The result printed as a "50-PATIENT CLINICAL BLAND-ALTMAN COHORT (N=50)" and plotted with an x-axis labeled "Mean of Spirometer GT & ResoNet Est" comes from 50 synthetic trials scored against the simulator's own programmed sine (Section 8 benchmark cell, lines 194, 208 and 262-267). Its r = 0.998 is expected by construction. Bland and Altman's first objection to correlation is that "r measures the strength of a relation between two variables, not the agreement between them" ([Bland and Altman 1986](https://www-users.york.ac.uk/~mb55/meas/ba.pdf)). The reported bias is -0.19 breaths/min (95% CI -0.33 to -0.05). The limits of agreement are -1.13 and +0.75, with CIs of -1.37 to -0.90 and +0.52 to +0.99. Yet the plot's fixed ±0.6 axis **hides both limit lines and, under a normal approximation, about a quarter of the points** (audit arithmetic, audit_scripts/report_checks.py). That breaks reporting items that require the limits to be plotted with their CIs ([Gerke 2020](https://www.doi.org/10.3390/DIAGNOSTICS10050334)). The "MIMIC-III" calibration tuned and tested on one record, and that record was the fallback sine. This is double dipping ([Kriegeskorte et al. 2009](https://www.nature.com/articles/nn.2303)), and it breaks TRIPOD+AI's rule that "Evaluation data should be distinct from the data used to train the model, tune hyperparameters, or do model selection" ([TRIPOD+AI](https://www.bmj.com/content/385/bmj-2023-078378)). The "CSI-Bench" label sits on self-generated data. The real CSI-Bench holds over 461 hours from 35 users in 26 environments, including ESP32-S3 devices, and its breathing labels are binary detections at 30 Hz, not rates ([CSI-Bench](https://arxiv.org/abs/2505.21866v2)). Cell_17 also contains a generator that writes "authentic" synthetic rows, in overwrite mode, to csi_logs/demo_20261019_015843.csv, the filename of the groupmate's real recording (Section 8 setup cell, lines 123-197). Any analysis of that path after the cell runs describes simulated data.

How these labels should be read depends on intent, and an audit cannot see intent. US research-misconduct rules define fabrication as "making up data or results and recording or reporting them" and exclude "honest error" ([42 CFR Part 93](https://www.ecfr.gov/current/title-42/chapter-I/subchapter-H/part-93/subpart-B)). The European code adds "Hiding the use of AI or automated tools in the creation of content" to its list of unacceptable practices ([ALLEA 2023](https://allea.org/wp-content/uploads/2023/06/European-Code-of-Conduct-Revised-Edition-2023.pdf)). Written as they are, these labels would meet those definitions if kept knowingly. Relabeled as in-silico verification, the same artifacts become legitimate simulation work, and ORI's guidance explicitly weighs corrective steps ([ORI honest-error guidance](https://ori.hhs.gov/sites/default/files/2025-09/Honest%20Error%20Guidance_final.pdf)). The practical fixes are straightforward. Put "SIMULATED" in every simulated title. Make fallbacks raise errors instead of silently continuing. Keep raw data read-only with a checksum manifest, as "Good enough practices" advises ([Wilson et al. 2017](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1005510)), and open generated files in exclusive-create mode so they can never overwrite a recording. Real evidence then needs a time-synchronized reference instrument. The peer-reviewed ESP32 studies used respiration belts and reported errors of roughly 1 to 3 breaths/min with one person in the scene: Bland-Altman limits of about 1.1 to 1.3 for paced breathing ([Alzaabi et al. 2024](https://doaj.org/article/af6425956d774801bfa35efac1f160c1)), and a 2.60 mean absolute deviation across 8 subjects ([Burimas et al. 2024](https://doaj.org/article/8aad8683e5dc44f8a55e87de1d021f4f)). Bland suggests about 100 subjects for usefully tight limits ([Bland sample-size FAQ](https://www-users.york.ac.uk/~mb55/meas/sizemeth.htm)). Two accepted middle steps are injecting known breathing into real empty-room CSV, as spike-sorting and gravitational-wave groups do with hybrid and injected ground truth ([SpikeForest](https://elifesciences.org/articles/55167); [LIGO injections](https://arxiv.org/abs/1612.07864)), and testing on a physical phantom, as NIST and FDA did, labeled openly as manikin data ([NIST/FDA BreatheSmart](https://www.nist.gov/node/1728046)).

## Triage rules sit looser than NEWS2 and are blind to infants

| Situation | V1.2 rule today | Published reference point | Suggested V2 behavior (adults 16+, to validate with local clinicians) |
|---|---|---|---|
| Very slow breathing | RED if RR < 8 | NEWS2 scores RR ≤ 8 as 3 points, a single-parameter red trigger | "Check now" if RR ≤ 8 is sustained over at least 60 s |
| Slightly slow | Nothing | NEWS2 scores 9-11 as 1 point | Low-priority note |
| Normal | GREEN; legend says "HEALTHY 12-24" | NEWS2 gives 0 points only at 12-20 | "No breathing-rate alert" at 12-20 |
| Raised | GREEN up to 25 | NEWS2 21-24 = 2 points; qSOFA ≥ 22; ESI adult danger zone > 20 | "Re-check soon" at 21-24 |
| Very fast | YELLOW if RR > 25 | NEWS2 ≥ 25 = 3 points | "Check now" if RR ≥ 25 is sustained |
| No breathing detected | RED after a 6 s pause | AASM adult apnea ≥ 10 s; pediatric central apnea ≥ 20 s | "Possible absent breathing" after at least 10 s with presence and good signal confirmed; escalate at 15-20 s |
| Poor signal | RED if PLV < 0.15; YELLOW "Tachypnea" if PLV < 0.60 | No clinical meaning | Grey "No reliable reading", never red or yellow |
| Infants and young children | Not handled; band tops out at 36/min, clamp at 39/min | Newborn median 44/min; WHO fast breathing ≥ 60, ≥ 50, ≥ 40 by age | Label "adults only", or add age bands, a band edge of at least 1.5 Hz, and pediatric validation |

Every major adult framework flags breathing in the low 20s. NEWS2 scores 21-24 as 2 points, and both ≤ 8 and ≥ 25 as 3 points ([MDCalc NEWS2](https://www.mdcalc.com/calc/10083/national-early-warning-score-news-2)). qSOFA counts RR ≥ 22 ([Surviving Sepsis Campaign 2021](https://emcrit.org/wp-content/uploads/2022/02/Evans2021_Article_SurvivingSepsisCampaignInterna.pdf)). ESI lists an adult RR above 20 as a danger-zone vital sign ([ESI v4 handbook](https://sgnor.ch/fileadmin/user_upload/Dokumente/Downloads/Esi_Handbook.pdf)). V1.2's "HEALTHY 12-24" legend (the v1.2 dashboard HTML in the Section 6 code cell) and its YELLOW threshold of > 25 therefore miss the entire 21-25 band, and its RED rule of < 8 excludes 8 itself. None of these frameworks maps a single abnormal rate to resuscitation. A single 3-point NEWS2 parameter triggers hourly monitoring and a medical assessment ([NHS Lothian NEWS2 chart](https://policyonline.nhslothian.scot/wp-content/uploads/2023/03/NEWS_Chart.pdf)). ESI v5 asks the triage nurse to reassess ([ESI v5 handbook](https://media.emscimprovement.center/documents/Emergency_Severity_Index_Handbook.pdf)). NEWS2 itself "should supplement clinical judgement" ([RCP](https://www.rcp.ac.uk/improving-care/resources/national-early-warning-score-news-2/)). The surviving sepsis guideline goes further and recommends against qSOFA "as a single screening tool". So the top tier should read "check this person now", and the system should make no sepsis claim at all. This audit found no DOH-mandated national emergency triage scale in the Philippines, so aligning tiers with "prompt a nurse to take full vital signs" avoids colliding with whatever color scheme each emergency department already uses.

The passband is the most consequential clinical gap for this market. Median breathing falls from **44/min at birth to 26/min at age 2** ([Fleming et al. 2011](https://pmc.ncbi.nlm.nih.gov/articles/PMC3789232)). WHO's fast-breathing cut-offs for pneumonia are 60, 50 and 40/min by age ([Pio, WHO Bulletin 2003](https://scielosp.org/article/bwho/2003.v81n4/298-300); [IMNCI chart booklet](https://sites.pitt.edu/~super1/Pirzado/Chartbooklet%202019%20Pakistan.pdf)). WHO's 2024 guideline defines severe tachypnea as 20/min above the age cut-off, up to 80/min in young infants ([WHO 2024 guideline](https://medbox.org/index.php/dl/6787c22c52d07f0dcc62ca62)). With a 0.60 Hz (36/min) band edge and a 39/min clamp, V1.2 cannot even represent normal infant breathing. The likely failure is a GREEN "Stable Eupnea" for a tachypneic baby, because the estimator locks onto residual low-frequency energy. That matters in a country where pneumonia was the **fourth-leading cause of death, 25,453 deaths (6.5%) in January to September 2024** ([PSA](https://psa.gov.ph/content/2024-causes-death-philippines-provisional-31-january-2025)), and the leading cause of infant deaths in DOH's 2016 statistics ([Inquirer](https://newsinfo.inquirer.net/1717228/preventable-60000-ph-children-die-per-year-before-5th-birthday/amp)). Children in Philippine waiting areas are also usually held by a caregiver, which creates two overlapping breathing sources in one CSI link. The honest options are an explicit "adults only" label, or age-banded thresholds with an upper band edge of at least 1.5 Hz and separate pediatric validation.

The 6 s apnea rule is shorter than every clinical definition. AASM scores adult apnea as a 90% or greater drop in airflow lasting at least 10 s, and pediatric central apnea at 20 s unless it comes with arousal, desaturation or bradycardia ([Berry et al., AASM 2012](https://jcsm.aasm.org/doi/10.5664/jcsm.2172)). AHA tells professionals to check a pulse for "no more than 10s" ([AHA 2025 BLS](https://cpr.heart.org/en/resuscitation-science/cpr-and-ecc-guidelines/adult-basic-and-advanced-life-support)). Talking, swallowing, coughing and sighing all interrupt breathing for seconds at a time, so a 6 s rule will fire on ordinary waiting-room behavior, although no study the research found measures how often. Signal loss compounds this. One ICU study logged **161,931 apnea or respiratory-rate alarms in 31 days**, including flat-line waveforms in patients who were breathing adequately ([Drew et al. 2014](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0110274)). Without presence detection, an empty chair looks exactly like apnea. At the slow end, agonal gasping at 3 to 6/min is attenuated by the 0.12 Hz edge and the 4.8/min clamp, so the low edge should move toward 0.05 Hz.

Accuracy targets should come from how breathing is actually counted. Manual counts vary by an interquartile range of about **3/min even over 60 s**, and 30 s samples can misclassify up to 40% of NEWS scores ([Drummond et al. 2020](https://www.research.ed.ac.uk/en/publications/current-clinical-methods-of-measurement-of-respiratory-rate-give-/)). 15 s counts underestimate by 2.19/min ([Hill et al. 2018](https://ideas.repec.org/a/wly/jocnur/v27y2018i3-4p546-554.html)). A commercial wearable patch failed a pre-declared ±3/min criterion, with limits of agreement of -15.8 to 11.2 ([Breteler et al.](https://bmjopen.bmj.com/content/8/2/e020162)). Because NEWS2 band edges sit only 1 to 4 breaths apart, sensible V2 targets are a bias within ±1/min and 95% limits within ±3/min (±2 near cut-offs). These should be measured in 60 s windows against an oronasal thermal sensor, inductance belt or capnograph, with sensitivity reported at RR ≤ 8 and ≥ 25.

Philippine conditions make false alarms especially costly. The PGH emergency room, designed for 75-80 patients, routinely carries 150-160 and has reached 180-200, with patients "in chairs or on the floor" ([Philstar](https://www.philstar.com/headlines/2025/03/28/2431761/critical-overcapacity-pgh-overwhelmed-patient-load-doubles-er)). East Avenue held 207 patients against a capacity of 150 (138%) ([Daily Tribune](https://tribune.net.ph/2025/08/06/eamc-er-exceeds-capacity-spox)). Government wards average one nurse per 20 patients against a DOH standard of 1:12 ([Inquirer](https://newsinfo.inquirer.net/?p=1851495)). The Joint Commission estimates that **85 to 99% of alarm signals need no intervention** and linked alarm-related events to 80 deaths ([Joint Commission SEA 50](https://digitalassets.jointcommission.org/api/public/content/f65e5c9df2b94000a99445e0a7877007)). A crowded room is also the worst case for CSI, with many bodies, constant movement and children held by caregivers. The regulatory stakes follow the wording. Under DOH AO 2018-0002, software can be a medical device, and classes B to D need registration ([AO 2018-0002](https://elibrary.judiciary.gov.ph/thebookshelf/showdocs/10/89924)). AMDD Rule 10 places devices monitoring vital parameters "where the nature of variations is such that" they could mean immediate danger, with respiration as an example, in Class C ([ASEAN Medical Device Directive](https://lawforasean.ocs.go.th/File/files/22_-September-2015-ASEAN-Medical-Device-Directive.pdf)). "Immediate Resuscitation" pushes toward that class, while "prompts staff to re-check" may argue for Class B. That classification is this audit's inference to confirm with FDA Philippines. Breathing data tied to a seat or queue number in a facility is health information about an identifiable person, which is sensitive personal information under RA 10173. Unauthorized processing carries **3 to 6 years' imprisonment and fines of PHP 500,000 to 4,000,000** ([Data Privacy Act](https://privacy.gov.ph/data-privacy-act/)). The NPC's CCTV circular, which does not expressly cover RF sensing, is still the obvious template: declared purpose, a privacy impact assessment, prominent notices, no sensing in toilets or lactation rooms, and minimal retention ([NPC Circular 2024-02](https://privacy.gov.ph/wp-content/uploads/2024/08/NPC-Circular-No.-2024-02-CCTV-Systems.pdf)).

## A calm four-state dashboard can be warm, bilingual and readable at 4 m

### Contrast, size and color-blind safety

The current interface fails the WCAG 2.2 AA floor of 4.5:1 for body text and 3:1 for large text and state-bearing graphics ([W3C, WCAG 2.2](https://www.w3.org/WAI/standards-guidelines/wcag/new-in-22); [WebAIM](https://webaim.org/articles/contrast/)). Slate-500 text on slate-800 measures **3.07:1**, white on the red-500 badge 3.76:1, and white on the green-500 badge **2.28:1**, failing even the large-text threshold ([palette_check.py](audit_scripts/palette_check.py)). Most text is set at 9.5 to 12 px in monospace (the v1.2 dashboard HTML in the Section 6 code cell). At desk distance that gives capital letters of about 9 to 11 arcminutes, roughly half the 16-arcminute minimum (20 is optimal) that display guidance derives from MIL-PRF-87268D ([Activu](https://activu.com/uploads/Optimal-Font-Size.pdf)). Color vision is a local issue too. A Manila study of 1,258 male high-school students found **5.17% color-deficient, 98% of them deutan** (red-green) ([Cruz et al. 2010](https://paojournal.com/index.php/pjo/article/view/294)). Under deutan simulation, the current Tailwind green and red both turn khaki, and the minimum color difference between states (ΔE00) falls to **7.8** ([palette_check.py](audit_scripts/palette_check.py)). The Royal College of Physicians replaced NEWS2's original red-amber-green chart for exactly this reason: those colors "were not ideal for staff with red/green colour blindness" ([RCP NEWS2 report](https://www.rcp.ac.uk/media/a4ibkkbf/news2-final-report_0_0.pdf)). A blue #1D6FA3, light-amber #FFCB47 and deep-red #9F1D14 triad keeps a minimum deutan ΔE00 of **41.1**, because it separates states by a lightness ladder plus a blue-versus-warm hue axis that dichromats retain ([palette_check.py](audit_scripts/palette_check.py); [Wong 2011](https://nature.berkeley.edu/garbelottoat/wp-content/uploads/nmeth.1618.pdf-WT.pdf)). Light should be the default theme, since dark backgrounds force every status color light and halve the worst-case separation (19.0). Sizes follow from viewing distance. A nurse-station monitor at about 0.7 m needs a 16 px minimum, 18-20 px body text and 40-48 px rate numerals. A 43-55 inch wall screen at 3 to 5 m needs a 40-65 px minimum and 96-160 px queue numbers. Atkinson Hyperlegible Next, built by the Braille Institute for low vision with seven weights and over 150 languages, or Inter with tabular figures, both work, provided live numbers use tabular-nums so they do not jitter ([Atkinson Hyperlegible](https://en.wikipedia.org/wiki/Atkinson_Hyperlegible); [Hyperlegible Next release](https://bakercityherald.com/?p=216504); [Inter](https://rsms.me/inter/)).

### Four states, each carried by words, shape and action

| State | Label (Filipino / English) | Shape | Light-theme color | Behavior |
|---|---|---|---|---|
| Urgent | Kailangan ng tulong ngayon / Needs help now | Filled triangle with "!" | Solid #9F1D14, white bold text (7.89:1) | Only state allowed to pulse or sound, and only at the staff station |
| Watch | Bantayan: susuriin ulit sa loob ng 10 minuto / Watch: recheck within 10 min | Diamond or clock | #FFCB47 fill, ink text (11.32:1), #8A5300 border | Steady; escalates only if left unacknowledged |
| No concern | Walang nakitang problema sa paghinga / No breathing concern found | Check in a circle | Neutral card, #1D6FA3 icon and text (5.45:1) | Quiet, no fill color |
| No reliable reading | Hindi mabasa ang paghinga / No reliable reading | Signal bars with a slash | #EDEBE8 tint, #5A534A text (6.37:1), dashed hatch | Never red or yellow; shows a fix-it prompt |

The fourth state is the most important change. The medical alarm standard IEC 60601-1-8 separates alarms caused by equipment faults from alarms caused by patient problems ([DigiKey eMedia](https://emedia.digikey.com/view/785457150/42-43)). It uses red for high priority and allows cyan for low priority, and its committee rejected symbol sets that could not be told apart at 4 m, noting that color-blind users need shape coding ([Har-El IEC 60601-1-8 commentary](https://standards.har-el.com/Projects/181701/60601-1-8/html/A2SubCl-6-3-2-2-Visual-Characteristics.htm); [Johner Institute](https://international.johner-institute.com/articles/product-development/and-more/iec-60601-1-8/)). Low coherence, motion, crowding and an empty seat should therefore map to grey "No reliable reading", never to RED "Immediate Resuscitation" or YELLOW "Tachypnea". Every patient alert should pass a signal-quality gate and a persistence window of 30 to 60 s first, mirroring the signal-quality suppression used in the PhysioNet false-alarm challenge ([Clifford et al. 2015](https://lcp.mit.edu/pdf/CliffordCinC2015.pdf)) and the configurable delays recommended after the UCSF ICU study logged **187 audible alarms per bed per day** ([Drew et al. 2014](https://pmc.ncbi.nlm.nih.gov/articles/PMC4206416)). One tap should acknowledge an alert, recording staff initials and time. Unacknowledged Urgent alerts should escalate, and every alert should be logged with its signal quality so the team can review its alarm burden weekly. The busy 3D point-cloud room belongs in an engineering view. Staff need a 2D seat map of large labeled chips, sorted Urgent, Watch, No reading, No concern, each paired with an action and a time, as the Manchester Triage System pairs every color with a name and a target time ([MTS summary](https://metricgate.com/docs/manchester-triage-priority/)).

### Plain Filipino first, English medical terms kept

Language access is not optional. Tagalog is the home language of only **39.9% of households**, followed by Bisaya/Binisaya (16.0%), Hiligaynon (7.3%), Ilocano (7.1%) and Cebuano (6.5%) ([PSA 2020 census](https://psa.gov.ph/system/files/phcd/02%20-Press%20Release%20on%20Language_Dialect%20Generally%20Spoken%20at%20Home_030323_PMMJ_CRD.pdf)). Functional literacy among Filipinos aged 10 to 64 stands at 70.8% ([FLEMMS 2024](https://journalnews.com.ph/ph-trumpets-high-basic-literacy-rate); [PSA FLEMMS release](https://rsso03.psa.gov.ph/sites/default/files/2025-06/FLEMSS.pdf)). In a 16-person qualitative study, Filipino mHealth users named English-only content as a barrier and asked for "bolder fonts, and larger field boxes and buttons", a plain white background, local-language options and clear privacy ([Gonzales et al. 2023](https://formative.jmir.org/2023/1/e41838/)). WHO Philippines' Tagalog health page models the register to aim for: Filipino sentence frames such as "hirap sa paghinga" (difficulty breathing) with medical terms kept in English ([WHO Philippines](https://www.who.int/philippines/emergencies/covid-19-response-in-the-philippines/impormasyong-pampubliko/alamin-ang-covid-19)). Text should target a reading age of 9 to 11 ([NHS content guide](https://service-manual.nhs.uk/content/how-we-write)) and score at least 90 on the CDC Clear Communication Index ([CDC CCI](https://Cdc.gov/ccindex/pdf/clear-communication-user-guide.pdf)). Concretely, every result view should carry "Paunang pagsusuri (screening) lamang ito, hindi diagnosis. Ang nurse o doktor ang magpapasya." ("This is a screening result, not a diagnosis. A nurse or doctor will decide."), which follows WHO's framing of screening as identifying people at higher risk ([WHO screening guide](https://www.who.int/europe/publications/i/item/9789289054782)). Rates should read "Paghinga: 28 kada minuto" as whole numbers. The no-reading prompt should say "Paki-upo po nang tuwid at huwag gumalaw" ("Please sit upright and stay still"). The public wall screen should show only queue numbers and general guidance such as "Kung nahihirapan po kayong huminga, sabihin agad sa nurse", never an identifiable person's result. These phrasings still need testing with Filipino nurses, barangay health workers and patients. Warmth comes from a warm off-white page (#FAF7F2) with white cards, one deep-teal brand color (#0B6B66), a mango accent kept to illustration, sentence case instead of "OTHERWISE (RED)", and visible trust signals: who runs the system, its calibration time, and what happens next. NHS uses a tinted background precisely because it "reduces glare" ([NHS design system](https://service-manual.nhs.uk/design-system/styles/colour)), and visual design was the most-cited credibility cue (46.1% of comments) in a 2,684-person study of how people judge websites ([Consumer Reports study](https://advocacy.consumerreports.org/research/how-do-people-evaluate-a-web-sites-credibility)).

### Figures that cannot mislead

Paper figures should be re-rendered on white with dark-grey text from one shared style file generated from the dashboard tokens. Use Okabe-Ito blue, vermillion, bluish green and reddish purple for lines, since all reach at least 3:1 on white ([palette_check.py](audit_scripts/palette_check.py)). Keep orange, sky blue and yellow for filled areas only. Pair every color with a marker shape and line style so figures survive greyscale printing and color-vision deficiency ([Wong 2011](https://nature.berkeley.edu/garbelottoat/wp-content/uploads/nmeth.1618.pdf-WT.pdf)). Spectrograms and CSI heatmaps should use cividis or viridis with a colorbar, never jet, because rainbow maps can misrepresent data by more than 7% of the displayed variation ([Crameri et al. 2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7595127); [Nuñez et al. 2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC6070163)). Every Bland-Altman plot should take its y-limits from the data, draw the bias and both limits with their numeric values and CI bands, and state n. Every simulated figure should carry "SIMULATED (in silico)" in its title. The team's EEG paper already uses Gardner-Altman estimation plots ([Ho et al. 2019](https://doi.org/10.1038/s41592-019-0470-3)), and they transfer directly.

## Conclusion

The audit changes the question the team should be asking. V1.2's weakest point is not the oscillator mathematics that dominates its write-up. It is the absence of any test that could fail. Every impairment that matters on hardware (sample rate, node pooling, null bins, gain steps, host-clock jitter, motion) is missing from the generator, and every headline metric was computed against that generator, so the pipeline has been tuned for a world that does not exist. A 173-second CSV with no ground truth exposed more real defects than all of the synthetic benchmarks combined. The next unit of effort therefore belongs in recordings, not models: a few belt-referenced sessions, empty-room captures for injection tests, and a frozen pipeline evaluated on people it has never seen. Accuracy on real people is currently unknown rather than known to be poor. Several quantities this audit could only bound also need measuring: ESP32 timing jitter, the receiver chip and its gain behavior, and which thresholds Filipino clinicians will act on.

The team already owns the playbook. Its ResoNet paper earned credibility by building a control that could have sunk its own hypothesis, and by reporting plainly that its oscillators were damped resonators that never self-oscillate. Bringing that discipline to Hinigram means naming the reservoir as a reservoir, replacing self-PLV with a quality index that is able to say "no", and treating a narrower claim as the stronger one: adults only, one link per chair, alerts that ask a nurse to re-check rather than declare resuscitation. That is also the better competitive position, since review checklists state that "Reviewers will be specifically instructed to not penalize honesty concerning limitations" ([NeurIPS checklist](https://neurips.cc/public/guides/PaperChecklist)). In a Philippine emergency room, a quiet tool that is right when it speaks is the only kind staff will keep listening to.
